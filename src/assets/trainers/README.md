# トレーナーの顔アイコン画像

チャットに表示するトレーナーのアイコンをここに置く。

## ファイル名(`src/lib/trainers.ts` の `TrainerId` と一致させる)

| ファイル名 | トレーナー | 元画像 |
| --- | --- | --- |
| `flow.png` | しなやか(ヨガ・ストレッチ) | 緑のウェアの女性・片手を上げたポーズ |
| `fresh.png` | さわやか(筋トレ・ボディメイク) | 黒ウェアの男性・ダンベル |
| `power.png` | パワフル(本格トレーニング) | 赤黒ウェアの女性・ホイッスル |
| `hard.png` | ストイック(ハード系) | 赤黒ウェアの男性・ホイッスル |

拡張子は `.png` / `.jpg` / `.jpeg` / `.webp` のいずれでもよい。

## 画像の条件

- **正方形で顔まわりだけを切り出したもの**(丸く切り抜いて表示するため)
- 256×256px 程度あれば十分。Artifactプレビューでは単一HTMLに埋め込まれるので、
  1枚あたり 50KB 以下を目安にする(大きすぎるとプレビューが重くなる)
- 全身画像しか用意できない場合は、`src/lib/trainers.ts` の `objectPosition` を
  `"50% 12%"` のように調整して顔の位置へ寄せる

## 未配置のときの挙動

ファイルが無くてもビルドは通り、丸の中に頭文字(し / さ / パ / ス)が表示される。
`import.meta.glob` で存在するファイルだけを拾う仕組みのため、
画像を置けば自動で読み込まれる(コード変更は不要)。
