# トレーナーの顔アイコン画像

チャットに表示するトレーナーのアイコン。**このフォルダ直下の画像がそのままアプリで使われる。**

| ファイル | トレーナー | 見た目 |
| --- | --- | --- |
| `flow.webp` | しなやか(ヨガ・ストレッチ) | 緑のウェアの女性 |
| `fresh.webp` | さわやか(筋トレ・ボディメイク) | 黒ウェアの男性・ダンベル |
| `power.webp` | パワフル(本格トレーニング) | 赤黒ウェアの女性・ホイッスル |
| `hard.webp` | ストイック(ハード系) | 赤黒ウェアの男性・ホイッスル |

ファイル名は `src/lib/trainers.ts` の `TrainerId` と一致させること。
拡張子は `.webp` / `.png` / `.jpg` / `.jpeg` のいずれでもよい。

## 仕様

- 256×256 の正方形。丸く切り抜いて表示するので**顔が中央**に来るようにする
- Artifactプレビューでは単一HTMLに埋め込まれるため、1枚 50KB 以下を目安にする
  (現状は webp で 9〜17KB)
- ファイルが無くてもビルドは通り、丸の中に頭文字が表示される
  (`import.meta.glob` で存在するものだけ拾うため、置けば自動で読み込まれる)

## 顔の位置を調整したいとき

元の全身画像は `originals/` にある。`scripts/crop-trainer-avatars.mjs` の
`cx` / `cy` / `size` を変えて再実行すれば切り出し直せる。

```bash
cd <作業dir> && npm i sharp   # リポジトリのpackage.jsonには追加しない
node scripts/crop-trainer-avatars.mjs
```

**`originals/` はサブフォルダに置くこと。** `lib/trainers.ts` の `import.meta.glob` は
このフォルダ直下だけを見る(非再帰)ため、直下に大きな元画像を置くとバンドルに巻き込まれる。
